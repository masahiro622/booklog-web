# booklog-web

自宅の蔵書（約4,600冊）の置き場所を探せる Web アプリ。**開発中。**

## 作る理由

蔵書は [ブクログ](https://booklog.jp/) で管理していて、「カテゴリ」欄に本棚の場所を入れている。
ただ、タイトルがうろ覚えだとブクログの検索では見つけられない。

そこで、自然な言葉で「あのバスケのマンガどこ？」と聞くと置き場所を返す Discord Bot
（[booklog-bot](https://github.com/masahiro622/booklog-bot)）を作った。
このリポジトリでは、それを Web アプリとして作り直している。目的は次の3つ。

- Discord を使わない同居人も、ブラウザから使えるようにする
- 置き場所を Web 上で直接直せるようにする（今は本を動かすたびに、ブクログで直して CSV を出し直している）
- 部屋や本棚ごとの一覧など、チャットでは見づらい表示をできるようにする

## 機能（予定）

- [ ] 書名・著者で検索して、置き場所を表示する
- [ ] ログイン（自分と同居人だけが使える）
- [ ] 置き場所を Web 上で編集する
- [ ] 自然文で検索する（Claude API）
- [ ] 部屋・本棚ごとに一覧を表示する

## 技術構成（予定）

TypeScript / Next.js（React）/ SQLite / Claude API
